# Dynamic Land Area & Bhoomi RTC Calculator
> An open-source, dual-language civic utility for real-time land area conversion, Bhoomi RTC record calculations, and survey plot estimation.

[![License: MIT](https://img.shields.io/badge/License-MIT-emerald.svg)](LICENSE)
[![Status: Active](https://img.shields.io/badge/Status-Active_Maintenance-success.svg)](#)

## 📌 Overview

**Dynamic Land Area & Bhoomi RTC Calculator** is a fast, client-side open-source tool designed to simplify land area measurement calculations and government RTC record conversions. Built specifically for farmers, surveyors, property buyers, and civil engineers, it eliminates complex manual math by providing instant conversions across standard regional and international land metrics.

### Key Features
- **Multi-Unit Conversions:** Instantly convert between **Acres, Gunthas, Cents, Square Feet, Square Meters, and Hectares**.
- **Bhoomi RTC Compatibility:** Dedicated conversion algorithms tailored to regional land records (RTC Pahani formats).
- **Dual-Language Interface:** Seamless support for both **English** and **Kannada (ಕನ್ನಡ)**.
- **Client-Side & Offline-Ready:** Zero server latency; works fully in the browser without network connectivity.
- **Responsive Modern UI:** Built with clean Tailwind CSS styling and accessible dark/light themes.

## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/govardan81a/dynamic-land-calculator.git
   cd dynamic-land-calculator
   ```

2. Open `index.html` in any modern web browser:
   ```bash
   # On Linux
   xdg-open index.html
   ```

No build steps or package managers required.
